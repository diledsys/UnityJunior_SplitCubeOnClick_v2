# Unity Project: UnityJunior_SplitCubeOnClick

## Описание
Учебный проект на Unity.
## Взрывы кубов
На сцене находится несколько кубов. При нажатии на куб он исчезает и появляются новые кубы, в случайном количестве от 2 до 6 штук.
У каждого нового куба Scale уменьшен в два раза по всем осям относительно того куба, на который нажал пользователь.
Цвет каждого куба определяется случайным образом.
На каждый куб действует сила гравитации.
Шанс разделения с каждым разом уменьшается в 2 раза начиная со 100%. При успехе идет разделение, иначе куб просто исчезает.
Добавить взрывную силу из центра исчезнувшего куба, которая разбросает только созданные им объекты.
Сделать невидимые ограждения, чтобы кубики далеко не разлетались

## MouseClickRaycaster
- Назначение
-  Отслеживает нажатие левой кнопки мыши
-  Строит Ray из камеры через позицию курсора
-  Выполняет Raycast по заданным слоям
-  Находит ближайший объект, реализующий интерфейс IClickable
-  Вызывает у него метод OnClick()

- Почему вынесен в отдельный объект
-  Не привязан к жизненному циклу кубов
-  Не уничтожается при делении объектов
-  Чётко разделяет Input и Game Logic

 -Ключевые особенности
-  Использует физический Raycast (без OnMouseDown)
-  Поддерживает большое количество объектов
-  Работает только со слоями, разрешёнными в LayerMask
-  Может визуализировать луч (для отладки)

## SplitCube
-  SplitCube отвечает за игровую логику деления куба и не знает ничего о вводе.

- Назначение
-  Реализует интерфейс IClickable
-  Реагирует на вызов OnClick()
-  Определяет, будет ли куб делиться или исчезнет
-  При успешном делении создаёт новые кубы меньшего размера

- Логика деления
-  Количество новых кубов: случайно от min до max
-  Размер каждого нового куба уменьшается в 2 раза по всем осям
-  Шанс деления для следующего поколения уменьшается в 2 раза
-  Каждому кубу задаётся случайный цвет без создания новых материалов

- Физика
-  Все кубы используют Rigidbody и подвержены гравитации
-  После деления применяется взрывная сила, влияющая только на созданные кубы
-  Минимальная масса ограничена, чтобы избежать нестабильной физики

- Важные детали
-  Новый куб наследует слой родителя, чтобы оставаться кликабельны
-  Деление прекращается при слишком малом шансе
-  Используется MaterialPropertyBlock для оптимизации памяти

## Архитектурный принцип
- Input и Game Logic разделены

-  MouseClickRaycaster — что кликнули
-  SplitCube — что с этим делать

- Такое разделение:
-  упрощает отладку
-  позволяет легко заменить способ ввода
